# Drayspo — Dray McFarlane portfolio

Static portfolio site (React + TanStack Start, prerendered), served at https://drayspo.com.

Application code on `main` is generated by the **Sync from upstream** workflow, so edits
made directly here are overwritten by the next sync. See `tools/upstream-sync/README.md`.

## Local development

```sh
bun install
bun run dev      # local dev server
bun run test     # unit tests
bun run build    # static site in dist/client
```
